# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and take criticism about the work and not the person, and do not harass anyone. This applies in issues, pull requests, discussions and anywhere else the project is represented.

To report a problem, contact the repository owner privately through their GitHub profile. Reports are kept confidential.
